模块中默认导出和命名导出的区别#

在 JavaScript 模块系统中，理解不同导出方式的行为差异对于避免潜在问题至关重要。本文将深入探讨默认导出和命名导出之间的关键区别。

命名导出：引用绑定机制#

命名导出创建的是实时绑定，这意味着导出的值会反映源模块中的任何更改。

// counter.js export let count = 0;

// 模拟值的变化 setTimeout(() => { count = 42; }, 500);

// main.js import { count } from './counter.js';

// 500ms后，count的值会更新为42 setTimeout(() => { console.log(count); // 42 }, 1000);

这种行为类似于"引用"或"指针"，导入的变量与源模块中的变量保持同步。

默认导出的两种形式#

默认导出有两种不同的行为，取决于使用的方式：

1. 表达式形式的默认导出#

// config.js let apiUrl = 'https://api.example.com';

export { apiUrl }; export default apiUrl; // 导出的是值的快照

setTimeout(() => { apiUrl = 'https://new-api.example.com'; }, 500);

// main.js import { apiUrl, default as defaultUrl } from './config.js'; import anotherUrl from './config.js';

setTimeout(() => { console.log(apiUrl); // "https://new-api.example.com" console.log(defaultUrl); // "https://api.example.com" console.log(anotherUrl); // "https://api.example.com" }, 1000);

在这种情况下，export default 导出的是表达式求值时的快照，不会反映后续更改。

2. 命名导出形式的默认导出#

// config.js let apiUrl = 'https://api.example.com';

export { apiUrl, apiUrl as default }; // 都是引用绑定

setTimeout(() => { apiUrl = 'https://new-api.example.com'; }, 500);

// main.js import { apiUrl, default as defaultUrl } from './config.js'; import anotherUrl from './config.js';

setTimeout(() => { console.log(apiUrl); // "https://new-api.example.com" console.log(defaultUrl); // "https://new-api.example.com" console.log(anotherUrl); // "https://new-api.example.com" }, 1000);

使用 export { thing as default } 形式时，创建的是引用绑定，行为与命名导出一致。

特殊情况：函数和类的导出#

函数和类的默认导出表现出引用绑定的特性，因为它们本身就是引用类型：

// utils.js export default function greet() { return "Hello!"; }

// 可以重新赋值函数 setTimeout(() => { greet = function() { return "Hi there!"; }; }, 500);

// main.js import greet from './utils.js';

setTimeout(() => { console.log(greet()); // "Hi there!" }, 1000);

循环依赖与变量提升#

模块间的循环依赖可能引发问题，特别是与变量提升相关的场景：

// 会正常工作 - 函数声明会被提升 // moduleA.js import { processData } from './moduleB.js'; processData();

export function formatData() { return "formatted"; }

// moduleB.js import { formatData } from './moduleA.js';

export function processData() { console.log(formatData()); // 正常工作 }

// 会出错 - const/let不会被提升 // moduleA.js import { processData } from './moduleB.js'; processData(); // ReferenceError

export const formatData = () => "formatted";

// moduleB.js import { formatData } from './moduleA.js'; // formatData还未初始化

export const processData = () => { console.log(formatData()); };

最佳实践建议#

  1. 明确导出意图：了解不同导出方式的行为差异
  2. 避免循环依赖：重构代码结构以消除循环依赖
  3. 谨慎修改导出值：尽量保持模块导出的不可变性
  4. 统一导出风格：在项目中保持一致的导出方式
